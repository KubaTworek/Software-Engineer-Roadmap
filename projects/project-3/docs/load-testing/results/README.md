# Wyniki eksperymentów obciążeniowych

Ten katalog zawiera wyłącznie raporty z faktycznie wykonanych eksperymentów.
Puste formularze znajdują się w [`../templates`](../templates/README.md).

Nazwij raport tak, aby wskazywał scenariusz i datę, na przykład
`2026-09-14-payment-timeout.md`. Do raportu dołącz:

- hipotezę i kryteria przerwania testu;
- wersję aplikacji oraz konfigurację środowiska;
- RPS, p95, p99, error rate i metryki nasycenia;
- dowód w postaci metryki, logu lub trace'u;
- wniosek, zastosowaną zmianę i koszt decyzji.

Nie zapisuj tu przykładowych liczb jako wyniku. Brak raportu oznacza, że dany
eksperyment nie został jeszcze wykonany.
